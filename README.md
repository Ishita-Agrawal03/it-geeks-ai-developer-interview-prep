## Core RAG Interview Questions

### RAG Pipeline

User query → query embedding → vector similarity search → top-k retrieved chunks → prompt/context construction → LLM → grounded response.

### Questions to Prepare

1. Why use RAG instead of fine-tuning?
2. What are embeddings and how are they generated?
3. Why did you choose FAISS?
4. How does cosine similarity work?
5. How do you choose chunk size and overlap?
6. What happens when retrieval returns irrelevant chunks?
7. How do you reduce hallucinations?
8. How would you evaluate retrieval quality?
9. How would you make a RAG application production-ready?
